# HamacWeb

Site web moderne et interactif développé avec **React**, **Vite** et **Tailwind CSS**.

## Fonctionnalités

- ⚡️ Construit avec Vite & React 19
- 🎨 Design moderne et responsive avec Tailwind CSS v4 & Lucide Icons
- 🌐 Prêt pour le déploiement sur Netlify (support SPA complet avec `_redirects` et `netlify.toml`)
- 📱 Interface optimisée pour mobile et desktop

## Installation et démarrage local

1. Installer les dépendances :
```bash
pnpm install
# ou
npm install
```

2. Démarrer le serveur de développement :
```bash
pnpm dev
# ou
npm run dev
```

3. Construire pour la production :
```bash
pnpm build
# ou
npm run build
```

## Déploiement sur Netlify

- **Build command:** `pnpm run build` (ou `npm run build`)
- **Publish directory:** `dist`
